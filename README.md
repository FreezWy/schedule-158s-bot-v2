# Telegram-бот расписания группы 158с

Бот скачивает актуальный Excel-файл с официального сайта колледжа, извлекает расписание группы **158с** и отправляет его в Telegram.

Источник расписания: https://medcol-ptz.ru/student/studies/

## Настройка

1. Откройте **Settings → Secrets and variables → Actions** в репозитории.
2. Создайте два repository secrets:
   - `TELEGRAM_BOT_TOKEN` — токен бота от BotFather.
   - `TELEGRAM_CHAT_ID` — ID личного чата, группы или канала, куда бот должен отправлять расписание.
3. Убедитесь, что бот добавлен в нужный чат и имеет право отправлять сообщения.

Не записывайте токены непосредственно в файлы репозитория и не публикуйте их.

## Запуск

- Автоматически: каждое воскресенье в 16:00 по московскому времени (GitHub Actions использует UTC).
- Вручную: **Actions → Send group 158s schedule → Run workflow**.

Первый запуск лучше выполнить вручную и проверить результат в Telegram и журнале GitHub Actions.

## Если запуск завершился ошибкой

Откройте **Actions**, выберите неудачный запуск и посмотрите лог шага **Send schedule to Telegram**. Возможные причины: изменился формат публикации на сайте, ещё не опубликован новый файл, неверные Secrets или бот не имеет доступа к чату.

GitHub Actions запускается по расписанию с возможной задержкой; это не гарантированный запуск ровно в указанную минуту.
